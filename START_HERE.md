## 🚀 Quick Start (5 Minutes)

### Step 1: Install Software
- Node.js from https://nodejs.org/
- Python from https://www.python.org/
- Ganache from https://trufflesuite.com/ganache/

### Step 2: Install Dependencies
```bash
cd backend
pip install -r requirements.txt

cd ../blockchain
npm install
```

### Step 3: Start Ganache
- Open Ganache app
- Click "QUICKSTART"
- Copy first account's private key

### Step 4: Configure & Deploy
- Update `.env` with private key
- Deploy smart contract:
```bash
cd blockchain
npx hardhat run scripts/deploy.js --network ganache
```
- Update `.env` with contract address

### Step 5: Run Server
```bash
cd backend
python app.py
```

Open: http://127.0.0.1:5000

## 🆘 Need Help?

### Common Issues:
- **"Command not found"** → Make sure Node.js/Python installed correctly
- **"Cannot connect"** → Make sure Ganache is running
- **"Port in use"** → Close other programs on port 5000/7545
- **"Module not found"** → Run `pip install -r requirements.txt` again
